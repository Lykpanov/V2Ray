Гайды на клиенты

Android / v2rayNG

  1. Скачайте и установите v2rayNG.
  2. Скопируйте ссылку на конфиг из списка выше.
  3. Откройте v2rayNG: сверху нажмите плюс и выберите импорт из буфера обмена.
  4. Проверьте задержку профилей и отсортируйте по результатам.
  5. Выберите сервер с наименьшим пингом и подключитесь.
download Скачать v2rayNG

Windows / Linux / Throne

  1. Скачайте Throne для своей системы.
  2. Скопируйте ссылку на конфиг в буфер обмена.
  3. В программе: Профили -> Добавить профиль из буфера обмена.
  4. Выполните тест задержки и включите режим TUN.
  5. Запустите конфиг с наименьшим пингом.
download Скачать Throne

iOS / macOS / Streisand

  1. Установите Streisand из App Store.
  2. Скопируйте ссылку на подписку.
  3. Откройте приложение и нажмите плюс для импорта из буфера.
  4. Проверьте задержку и активируйте подключение.

Как подключить прокси в Telegram

На ПК:

  1. Откройте Telegram и перейдите в Настройки (три полоски слева).
  2. Выберите «Данные и хранилище» -> «Прокси».
  3. Нажмите «Добавить прокси» и укажите параметры SOCKS5, HTTP или MTProto.

На телефоне:

  1. Откройте Настройки -> «Данные и хранилище» -> «Прокси».
  2. Добавьте прокси (для MTProto поддерживается прямая ссылка-приглашение).
  3. Включите тумблер использования прокси.
