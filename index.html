V2Ray Конфигурации

BLACK_FULL

Максимальный набор серверов для бескомпромиссной производительности.

BLACK_LTE

Оптимизированные конфигурации специально для мобильного интернета.

Инструкции к клиентам

v2rayNG (Android / TV)

Универсальный клиент для мобильных устройств на Android.

  1. Установите и откройте приложение.
  2. Скопируйте нужную ссылку выше.
  3. Нажмите «+» и выберите импорт из буфера обмена.
Скачать v2rayNG APK

Throne (Windows / Linux)

Современный десктопный клиент с поддержкой TUN-режима.

  1. Установите программу на ПК.
  2. Добавьте профиль из буфера обмена.
  3. Активируйте TUN-режим для всей системы.
Скачать для Windows

Streisand (iOS / macOS)

Удобный и быстрый клиент для экосистемы Apple.

  1. Установите Streisand из App Store.
  2. Импортируйте скопированную подписку.
  3. Выберите быстрый сервер и включите тумблер.
Открыть в App Store

Hiddify (Desktop / Mobile)

Многофункциональный клиент с интеллектуальной маршрутизацией.

  1. Установите приложение Hiddify.
  2. Добавьте новый профиль подписки.
  3. Запустите защищенное соединение.
Скачать Hiddify

WHITELIST Proxy
